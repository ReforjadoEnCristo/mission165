# Missing 3D head renders

The flat green-target / red-takeover body diagrams are gone. Each head now shows a 3D studio image when one exists. If that exercise has no head-specific file, the card uses its main studio photo and the head name as the caption. This list is every head that still has no file of its own.

Suggested names are new files to generate in the same style as `ex_hip_thrust.jpg`: dark studio, silver-grey resting muscle, red primary, orange secondary.
